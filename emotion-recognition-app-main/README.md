## 🌟 Features
- **Real-time Emotion Detection**: Analyzes your webcam feed instantly.
- **Deep Learning Powered**: Uses a pre-trained Keras model (`best_emotion_model.h5`) for high accuracy.
- **Interactive UI**: Built with Streamlit for a smooth and cute user experience.

## 🛠️ Tech Stack
- **Python 3.11** 🐍
- **Streamlit** (Frontend & UI) 🎈
- **TensorFlow / Keras** (Deep Learning) 🧠
- **OpenCV** (Image Processing) 📷

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shravu2215/emotion-recognition-app.git
   cd emotion-recognition-app
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```bash
   streamlit run app.py
   ```
